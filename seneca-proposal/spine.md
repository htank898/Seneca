# Seneca client proposal: message spine

**Audience:** potential clients (business decision-makers), live meeting.
**Moment:** a presented proposal, followed by a leave-behind they read afterwards.

## The answer
Seneca turns Claude from a file-maker into a communications lead. You tell it who you're talking to and what's at stake, and it decides what to make and builds it: decks, PDFs, graphics, GIFs, and interactive guides, in one consistent design anyone can open.

## Three supporting points
1. **It chooses the format, not just fills it.** Cowork's built-in skills make the file you name (Word, PowerPoint, Excel, PDF). Seneca starts from the audience and the moment, writes the message once, and picks the smallest set of formats where each has a job.
   *Evidence:* "Exec meeting Thursday" becomes a deck plus a one-page pre-read. "CRM rollout to 40 reps" becomes an interactive guide, a walkthrough GIF, and a cheat sheet.
2. **It makes formats an Office file can't be.** Click-through software guides, looping GIFs, platform-exact graphics with safe-zone checks, PDFs on custom stationery.
   *Evidence:* the examples in the repo, including a LinkedIn home-screen guide, the any-format GIF, the Mérida letter, and the banner set.
3. **It's built the way AI works best, and you own it.** Everything is HTML/CSS/JS rendered by a real browser engine, so you get exact typography, layout, and motion without fighting a file format. It's an MIT-licensed set of plain-text skills you can fork, brand, and extend.
   *Evidence:* the deck you're watching is one HTML file. Cowork installs plugins straight from a GitHub repo.

## Honest boundary
If the recipient needs to edit the file in PowerPoint or Excel (live formulas, a corporate template), use Cowork's built-in Office skills. Seneca is for when the message has to land. The two are complementary: Seneca installs as a plugin.
