Seneca · AI-first communication

Tell it who. It decides what.

The right deck, document, graphic, GIF, or guide for every audience, built by Claude in one consistent design.

Seneca is a set of skills for Claude. You describe the situation, like who's in the room and what you need from them, and it decides what to make and then makes it. Everything in this meeting, including this deck, was made with it.

AI can make any format in minutes. We still ask it for a PowerPoint.

The format we default to is the one that used to be affordable. That constraint is gone, but the habit isn't.

An interactive training replica used to be a developer's week. A custom animated explainer used to need a motion designer. Now each takes minutes, but teams still default to a deck or a doc because that's what was cheap before.

"Budget review with the CFO Thursday" → 6-slide deck + one-page pre-read + stat card for the team channel

The key difference is step 3. Seneca chooses the formats. Another example: "We're rolling out the new CRM to 40 reps" gives you an interactive practice guide, a walkthrough GIF, and a one-page cheat sheet.

Better together

Not a replacement. A plugin.
