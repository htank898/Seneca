Seneca · AI-first communication

Tell it who. It decides what.

Seneca turns Claude from a file-maker into a communications lead. Tell it who you're talking to and what's at stake. It decides what to make, then builds it: decks, PDFs, graphics, GIFs, and interactive guides, in one consistent design anyone can open.

1

It chooses the format

Seneca starts from the audience and the moment, writes the message once, and picks the fewest formats where each one has a job.

"Exec review Thursday" → a deck plus a one-page pre-read. "CRM rollout to 40 reps" → a practice guide, a walkthrough GIF, and a cheat sheet.

2

Formats Office can't be

Click-through software guides that coach each step, seamless looping GIFs, graphics at exact platform sizes with safe-zone checks, and PDFs on custom stationery.

Examples of each are in the GitHub repo.

3

Built for AI, owned by you

Everything is HTML, CSS, and JavaScript rendered by a real browser engine, so you get exact type, layout, and motion. It's MIT-licensed plain-text skills you can fork, review, and brand.

The deck from today's meeting is a single HTML file made with Seneca.

Getting started

  • Install as a plugin in Claude Code:/plugin marketplace add https://github.com/htank898/Seneca.git/plugin install seneca@seneca
  • Ask in plain words: "/seneca I have a board update Friday. Here are the numbers."
  • Share the files. Recipients don't need Claude or any special software.
